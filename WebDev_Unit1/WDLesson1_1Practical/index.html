Web Technologies

HTML

HTML stands for Hyper Text Markup Language, the standard markup language for creating Web pages. It's describes the structure of a Web page and consists of a series of elements. HTML elements tell the browser how to display the content and used HTML elements label pieces of content such as "this is a heading", "this is a paragraph", "this is a link", etc.

CSS

CSS is the language we use to style an HTML document. It describes how HTML elements should be displayed.We used it transforms the plain-text skeleton built with HTML into modern web pages that are aesthetically pleasing, well-formatted, and responsive.

JavaScript

JavaScript is a versatile, high-level programming language that infuses web pages with dynamic interactivity and core functionality. It responds in real-time to user events—such as clicks, scrolling, and keyboard input—and can even handle complex logical calculations and intricate graphical animations. We used it infuses life into the page by adding dynamic behavior and interactivity. It allows the page to react instantly to user input without requiring a full page reload.

JQuery

jQuery is a lightweight, open-source JavaScript library designed to simplify HTML DOM manipulation, event handling, animation, and Ajax interactions. Its core philosophy is "write less, do more", wrapping complex, multi-line vanilla JavaScript tasks into simple methods that can be called with a single line of code. We used it to Simplified DOM Manipulation, Cross-Browser Compatibility, Easier Ajax Requests, Built-in Animations and Effects, and Massive Plugin Ecosystem.
